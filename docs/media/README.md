# 展示素材

[← 返回项目首页](../../README.md)

这些素材用于 GitHub README，采用项目的米色、墨绿和金色视觉风格。

| 文件 | 内容 |
| :--- | :--- |
| `hero.png` | 项目图标、介绍文案与当前控制台截图组成的封面 |
| `control.png` | 使用示例数据的控制台截图 |
| `diary.png` | 使用示例日记的日记本截图 |
| `whip.gif` | 实际物理鞭子组件随鼠标运动、放手后落下 |
| `reward.gif` | 实际画饼组件绘制轮廓与兑现动画 |
| `diary.gif` | 实际日记本展开、翻页与筛选 |
| `cli-update.gif` | 实际更新界面的提示、等待状态与结果展示 |
| `divider.svg` | 可随 GitHub 页面宽度缩放的装饰分隔线 |

GIF 来自本地当前项目的前端组件，使用隔离的示例数据和模拟原生命令。背景中的 Codex 会话是演示背景，日记为展示文案；CLI 更新演示模拟更新结果，不执行真实安装。素材不包含用户的真实会话、登录凭据或个人数据。

GIF 自动循环播放，不包含声音。封面和截图为 PNG，装饰线为 SVG；首页通过仓库相对路径引用，随仓库发布即可展示，无需额外图床。

临时录制帧、浏览器配置与生成脚本保存在本地忽略目录 `.cache/readme-media/`。更新素材时重新录制当前组件，避免截图与实际界面不一致。
