## VibeKarma v0.2.0

### 新增与完善

- 自动检测实际调用的 Codex CLI 版本，支持按 npm、Homebrew 或官方独立安装方式更新。
- 更新前核对路径与版本，更新后验证同一路径；桌面客户端内置 CLI 不直接替换。
- 更新失败时展示可复制的排查说明，包含安装方式、版本、路径与错误摘要，并隐藏常见凭据。
- 更新成功后重试本次运行中的失败日记，保留原来的时间、原因与上下文，无需重复奖惩。
- Mac 接入当前窗口文本读取，提供辅助功能授权入口；无权限或读取失败时提示并降级生成日记。
- 调整更新界面，重写项目首页并增加四段功能演示 GIF。

### 安装包

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `VibeKarma_0.2.0_x64-setup.exe` |
| Windows x64 | `VibeKarma_0.2.0_x64_en-US.msi` |
| Mac Apple Silicon | `VibeKarma_0.2.0_aarch64.dmg` |
| Mac Intel | `VibeKarma_0.2.0_x64.dmg` |

建议安装并登录外部 Codex CLI。Mac 读取聊天需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 VibeKarma；未授权仍可奖惩和生成日记。生成素材由本机配置的 CLI / Provider 处理。

### 验证与使用限制

- Actions 在 Windows、Mac Intel 与 Apple Silicon 上检查测试、构建、安装包版本及基础原生启动；基础启动检查验证进程存活和本地数据库初始化。
- Actions 不代替实际 Codex 会话、人工权限授权、多窗口和多显示器测试。Mac 聊天读取及更新的交互验证仍待完成，详细范围见 [Mac 验证说明](https://github.com/Li-Rui-Zhe/VibeKarma/blob/main/docs/MACOS_VERIFICATION.md)。
- 失败日记队列仅保留在当前应用运行期间，关闭应用后不会保留。
- 安装包尚未签名，系统可能显示安全提醒。

此 Release 保留为草稿，安装与运行确认后再正式发布。
