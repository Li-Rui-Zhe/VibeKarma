## VibeKarma v0.2.0

### 新增与完善

- 自动检测实际调用的 Codex CLI 版本，支持按 npm、Homebrew 或官方独立安装方式更新。
- 更新前核对路径与版本，更新后验证同一路径；桌面客户端内置 CLI 不直接替换。
- 更新失败时展示可复制的排查说明，包含安装方式、版本、路径与错误摘要，并隐藏常见凭据。
- 更新成功后重试本次运行中的失败日记，保留原来的时间、原因与上下文，无需重复奖惩。
- Mac 接入当前窗口文本读取，提供辅助功能授权入口；无权限或读取失败时提示并降级生成日记。
- 调整更新界面，重写项目首页并增加四段功能演示 GIF。

### 安装包

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `VibeKarma_0.2.0_x64-setup.exe` |
| Windows x64 | `VibeKarma_0.2.0_x64_en-US.msi` |
| Mac Apple Silicon | `VibeKarma_0.2.0_aarch64.dmg` |
| Mac Intel | `VibeKarma_0.2.0_x64.dmg` |

建议安装并登录外部 Codex CLI。Mac 读取聊天需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 VibeKarma；未授权仍可奖惩和生成日记。生成素材由本机配置的 CLI / Provider 处理。

### 🍎 Mac 注意事项

- M 系列芯片选择 `aarch64.dmg`，Intel 芯片选择 `x64.dmg`；将应用拖入“应用程序”后再启动。
- 当前安装包没有开发者签名与公证。首次打开若提示开发者无法验证，确认下载来源后，按照 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 在“系统设置 → 隐私与安全性”中选择“仍要打开”。
- 在“隐私与安全性 → 辅助功能”中允许 VibeKarma，再重新检测。若授权或更新后未生效，退出应用后重开，必要时重新授权。
- 保持 Codex 聊天窗口可见；没有权限、窗口无法匹配或读取超时时会说明原因，日记使用反馈原因和近期日记继续生成。
- 外部 CLI 支持识别 Homebrew、npm 与官方独立安装方式；桌面客户端内置 CLI 需要更新客户端。CLI 检查、更新和日记生成需要对应服务可访问，应用不会自动开启代理。
- 详细安装和排查步骤见 [Mac 使用说明](https://github.com/Li-Rui-Zhe/VibeKarma/blob/main/docs/MACOS.md)。

### 验证与使用限制

- 本版本的 [CI](https://github.com/Li-Rui-Zhe/VibeKarma/actions/runs/38194684854) 与 [打包检查](https://github.com/Li-Rui-Zhe/VibeKarma/actions/runs/38195240433) 已通过。Windows、Mac Intel 与 Apple Silicon 均完成原生构建与基础启动检查，四种安装包完成版本及架构校验。基础启动检查验证进程存活和本地数据库初始化。Mac 在 DMG 打包前检查 `.app` 启动；Windows 在打包后检查原生程序启动，均不代替安装程序交互测试。
- Actions 不代替实际 Codex 会话、人工权限授权、多窗口和多显示器测试。Mac 聊天读取及更新的交互验证仍待完成，详细范围见 [Mac 验证说明](https://github.com/Li-Rui-Zhe/VibeKarma/blob/main/docs/MACOS_VERIFICATION.md)。
- 失败日记队列仅保留在当前应用运行期间，关闭应用后不会保留。
- 安装包尚未签名，系统可能显示安全提醒。

### 🐛 问题反馈

遇到 Bug，欢迎 [提交 Issue](https://github.com/Li-Rui-Zhe/VibeKarma/issues/new?template=bug_report.yml)。请附系统版本、设备架构、VibeKarma / Codex CLI 版本、复现步骤与错误摘要；Mac 问题请补充授权状态和显示器情况。提交前移除密钥、私人聊天与个人路径。
